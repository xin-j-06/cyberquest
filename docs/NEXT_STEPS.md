# CyberQuest 2.0 后续执行清单

最后更新：2026-09-13

## 当前基线

- Vue 3 + NestJS 本地系统可在 `http://127.0.0.1:5173` 完整运行，默认后端为 `http://127.0.0.1:3000/api`。
- 账号注册、登录、积分、题目完成、能力经验、训练会话、题目笔记、通知公告、赛事、工具目录、日历备忘和论坛讨论均由后端持久化；默认使用本地 JSON，也保留 Prisma/PostgreSQL 仓储实现。
- 六道题均已改为独立 CTF 靶场：启动后在新标签页打开目标网页或材料分析页，学员自行找到动态 Flag，再回工作台提交。
- 六题官方题解与实际靶场机制一致；未通关统一消耗 20 积分解锁，通关后免费查看。
- 题目笔记支持同题多篇追加保存、个人中心弹窗查看和按记录删除，浏览器仅保留缓存。
- 常用工具、能力图谱、独立知识库、相关赛事、技术论坛、首页赛事日历、个人中心和排行榜均已完成当前版本页面。
- 首页原“推荐下一步”已替换为赛事日历，可按日期查看管理员发布的实时赛事，并维护当前账号的报名、组队和训练备忘；个人中心继续保留“继续训练”。
- 首页“近期活动”已替换为“通知公告”，只展示管理员发布的有效公告。
- 管理员用户 CRUD 与公告 CRUD 后端接口已经完成角色校验；普通用户访问管理接口返回 403，管理响应不包含密码哈希。
- `/admin` 管理后台已完成独立布局与路由隔离，包含概览、题目管理、工具管理、赛事管理、用户管理、通知公告和意见反馈七个可操作页面。
- 登录会话默认有效期为 12 小时；失效 Token 会静默清理并跳转登录页，不会在登录表单显示“访问令牌失效”。
- Prisma migrations 和交接文档已同步到当前实现；OpenAPI 3.1 契约仍需补录赛事、日历备忘、论坛、反馈和工具管理的新增接口。

## 已完成：技术论坛

- 顶部导航在“相关赛事”后新增 `/forum`，提供技术问答、解题交流、工具与环境、资源分享四类讨论。
- 支持搜索、分类筛选、热门主题、发布讨论、查看楼层和回复；主题作者与管理员可删除主题及关联回复。
- 主题、回复、浏览量与作者快照由后端持久化，发帖和回复接口带频率限制；PostgreSQL 部署需应用迁移 `20260912161000_add_forum`。

## 已完成：管理员后台管理中心基础版

### 1. 管理端基础框架

- 已新增 `/admin` 独立布局、左侧侧边栏、仪表盘和管理员路由守卫。
- 前端进入管理路由前校验 `ADMIN` 角色；服务端继续作为最终权限边界。
- 提供用户数、公告数、题目数、近期管理操作等概览卡片。
- 管理操作增加明确的成功提示、失败提示和危险操作二次确认。

### 2. 用户管理页面

- 已对接 `GET/POST /api/admin/users`，支持列表、搜索、角色筛选和创建账号。
- 已对接 `PATCH /api/admin/users/:id`，允许修改昵称、邮箱和角色。
- 已对接 `DELETE /api/admin/users/:id`，删除前提示关联的笔记、解题记录和训练会话会一并清理。
- 保持“管理员不能删除当前登录账号”的后端约束。

### 3. 通知公告管理页面

- 已对接 `GET/POST /api/admin/announcements`，实现公告列表、创建表单和草稿保存。
- 已对接 `PATCH/DELETE /api/admin/announcements/:id`，支持编辑、发布、下架和删除。
- 增加标题/正文长度提示、发布时间、发布人和状态筛选。
- 学员首页继续通过 `GET /api/announcements` 只读取已发布公告。

### 4. 题目与内容管理

- 已新增管理员题目 CRUD API 与统一管理页面，Flag 只允许写入并在服务端哈希，任何读取接口不得返回明文或哈希。
- 已提供题目发布/下架、复制、管理员试玩、配置诊断、靶场模板、知识能力关联、实例列表和强制停止功能。
- 已支持在题目编辑器维护结构化官方题解（摘要、原理、复现步骤与预期结果），并复用现有 20 积分解锁/通关免费开放规则。
- 已补齐分类、难度、积分、标签、动态 Flag、靶场类型、TTL、错误提交量与平均解题时间字段；PostgreSQL 部署时需应用新增 Challenge 管理字段迁移。
- 待新增附件上传白名单、大小限制、文件名规范化和删除审计；在此之前继续只允许下载仓库内审核过的题目附件。
- 新增知识库专题和课程管理接口，避免继续把大量内容硬编码在前端组件中。
- 所有管理写操作记录管理员、目标资源、时间和变更摘要。

### 5. 工具管理

- 管理侧栏在“题目管理”下方新增 `/admin/tools`，支持工具新增、编辑、发布/下架、删除、搜索和状态筛选。
- 可维护工具名称、图标缩写、分类、用途说明、适用平台、官方来源、使用路径、官网/下载地址、按钮文字、安装命令、推荐状态和展示顺序。
- 学员端 `/tools` 已改为读取 `GET /api/tools` 的已发布数据；管理员通过 `GET/POST /api/admin/tools` 和 `PATCH/DELETE /api/admin/tools/:id` 维护完整目录。
- 工具数据支持本地 JSON 与 Prisma/PostgreSQL 两套仓储；PostgreSQL 部署需应用迁移 `20260913110000_add_training_tools`。
- 已验收新增后学员端可见、下架后隐藏、删除后移除，临时验收数据已清理。

### 6. 赛事与日历

- 管理后台 `/admin/competitions` 支持赛事创建、编辑、发布/下架、删除、推荐与时间安排，学员端 `/competitions` 只展示已发布赛事。
- 首页赛事日历聚合 `GET /api/competitions` 与当前账号 `GET /api/calendar/memos`，显示比赛起止时间、报名截止日和个人备忘。
- 备忘录通过 `GET/POST /api/calendar/memos`、`PATCH/DELETE /api/calendar/memos/:id` 按账号持久化，支持新增、编辑和删除。
- PostgreSQL 部署需应用赛事与日历备忘对应迁移，包括 `20260912183000_add_calendar_memos`。

### 7. 意见反馈闭环

- 学员端右侧固定反馈入口支持系统错误和优化建议，并自动记录当前页面。
- `POST /api/feedback` 持久化反馈并限制提交频率；管理员通过 `GET/PATCH/DELETE /api/admin/feedback` 查看、处理和清理记录。
- 管理页面提供关键词、反馈类型和处理状态筛选，支持管理员备注及待处理、处理中、已解决状态流转。

## 数据库与部署阶段

1. 启动真实 PostgreSQL 测试环境，设置 `DATA_BACKEND=prisma` 并依次执行现有 migrations。
2. 验证账号、单题多笔记、公告、赛事、日历备忘、工具目录、积分、提示解锁、动态 Flag 和管理员 CRUD 的 Prisma 端到端行为。
3. 为数据库迁移补充回滚策略、备份步骤和初始化管理员说明。
4. 用户确认进入容器化阶段后，再接入 PostgreSQL/Redis、私有网络、非 root 容器、资源限制和 TTL 清理。
